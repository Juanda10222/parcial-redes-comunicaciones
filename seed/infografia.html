Modelo OSI aplicado

capas 2–7
L7 Aplicación. Cabeceras Host / X-Forwarded-For / X-Forwarded-Proto de nginx; upgrade HTTP→WebSocket para el kernel de Jupyter.
L4 Transporte. TCP 80 (nginx), 5432 (postgres), 8888 (jupyter), 3000 (grafana); conexiones persistentes hacia la base de datos.
L3 Red. DNS embebido de Docker (127.0.0.11) resuelve nombres de servicio; NAT del host para el puerto publicado.
L2 Enlace. Interfaces veth conectadas a los bridges virtuales; resolución ARP entre contenedores del mismo bridge.
